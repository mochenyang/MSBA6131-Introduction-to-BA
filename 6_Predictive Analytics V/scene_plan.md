# Scene 2

**Text**: So far, we have been focusing on classification, which is the task of predicting categorical outcomes. Numeric prediction instead tries to predict numeric or continuous outcomes. However, that does not mean we need to invent everything from scratch. Some of the classification techniques, including k-nearest-neighbor and decision tree, can be naturally extended to serve the purpose of numeric prediction.

Using k-NN for numeric prediction is very straightforward. After finding the k nearest neighbors, instead of using the majority class as the prediction, we take the average of outcome values and use that as prediction.

Similarly, decision tree can also be adapted for numeric prediction, and it is sometimes referred to as the regression tree. It follows the same recursive partitioning algorithm. There are only two key differences. First, at each leaf node, instead of using the majority class as prediction, we again rely on the average of the outcome variable as prediction. Second, the metric of data purity, which is needed to determine how to split the tree, is different. We cannot use entropy anymore, because entropy is only defined for categorical outcome variables. Instead, we rely on sum of squared deviations as a measure of purity. When deciding how to split the tree, we will look at the sum of squared deviations from the average outcome values in each resulting leaf node, and choose the split that gives the smallest sum of squared deviations. This is because, intuitively, smaller sum of squared deviations indicates that the outcome values are closer to their average, which means they are closer to each other, and therefore the data is more pure.

# Scene 3

**Text**: A major difference between numeric prediction and classification is performance measurement. Because we are no longer predicting categorical outcomes, the concepts of accuracy, precision, recall, and f-measure no longer apply. In numeric prediction, the goal is for the prediction to be as close to the true value as possible. Therefore, we define the prediction error to be the difference between prediction and the actual outcome. Based on prediction error, we can define a number of performance metrics, including mean absolute error, mean absolute percentage error, rooted mean squared error, total sum of squared error, and average error. Among them, RMSE and MAE are the most commonly used ones.

Notice that average error is typically not an informative performance measure, because positive error can cancel out with negative error. Therefore, a small average error does not mean that the model is more accurate in its predictions. This is also why all the other performance metrics either take the absolute value or the square of the error, so that error direction does not matter anymore.

# Scene 4

**Text**: Next, we will discuss linear regression as a numeric prediction technique. Typically, linear regression is introduced in a statistics course, as one of the most important tools to estimate a statistical model and draw inferences or test hypotheses. However, the same mechanics of linear regression can be used for predictive purposes.

In a linear regression, the predicted outcome variable, Y-hat, is simply a linear combination of all the features. When there is only 1 feature, linear regression is the same as fitting a line through training data points. When there are more than one features, this becomes fitting a plane through space. The parameters of a linear regression are called the coefficients, and they represent the individual weights of each feature in determining the outcome variable. Each coefficient carries a straightforward interpretation. For instance, consider the coefficient b_1 on feature X_1: it means that 1 unit change in X_1 is associated with b_1 units change in the predicted value Y-hat, holding everything else unchanged.

# Scene 5

**Text**: How do we fit a linear regression? The idea is to find the coefficient values that fit the training data as well as possible. Typically, this is done by minimizing the so-called sum of squared error (SSE in short) on the training dataset. Take a look at this example for illustration. Given a regression line through these data points, we can measure how far each data point is from the predicted value given by the regression line. Adding up the squared value of these distances would produce the SSE. Different coefficient value correspond to different positions of this line, and we want to choose the coefficient values such that the SSE measure is the smallest.
